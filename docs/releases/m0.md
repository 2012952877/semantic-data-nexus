## Supported M0 scenarios

### Simple regional quarterly profit

- Initializes a fixed evaluation clock and semantic context.
- Compiles `SELECT -> FILTER -> AGGREGATE -> SORT -> PROJECT`.
- Executes against deterministic synthetic sales data.
- Returns committed regional profit rows, result manifest, diagnostics, and
  logical/physical/source/result lineage.

### Complex monthly profit comparison

- Compiles and executes `AGGREGATE -> PIVOT -> DERIVE -> PROJECT`.
- Keeps `PIVOT`, `DERIVE`, and `PROJECT` local to the runtime.
- Returns committed current/previous values and derived profit change with
  manifest and lineage.

Both scenarios use checked-in synthetic data and a deterministic compiler.

## Security and operations summary

- Fake execution is the default and only automatic release execution mode.
- Live Databricks requires a separate Compose override, profile, current-shell
  credentials, reviewed grants, and bounded read-only statements.
- Root Compose publishes only the loopback Web port and protects its fixed
  Development identity with Host and Origin gates.
- Containers are non-root, read-only, capability-dropped, and
  `no-new-privileges`.
- Contract validation is repeated at Web, BFF, compiler, planner/runtime,
  resolver, result commit, and BFF-detail boundaries.
- Logs and diagnostics exclude questions, SQL, rows, credentials, private hosts,
  connection strings, and provider payloads by design.
- Azure IaC is statically validated only; deployment and post-deployment
  evidence are not part of M0.

See the [M0 runbook](../operations/m0-release.md) and
[sequence document](../architecture/m0-sequence.md).

## Known limitations and non-goals

- Only two deterministic synthetic semantic scenarios are supported.
- No LLM invocation is present in M0.
- Control-plane state, backend run state, and inline results are process-local
  and non-durable.
- Restart recovery, distributed coordination, PostgreSQL repository adapters,
  and durable Blob/Parquet result storage are future work.
- Web HTTP mode does not expose ontology or browser-component-health endpoints.
- Live Databricks is skipped by CI and requires operator-controlled credentials,
  grants, and source data.
- The Azure baseline has no checked-in deployment, restore, reliability, cost,
  or production-network smoke evidence.
- Private endpoints, controlled egress, production edge/WAF, durable telemetry
  policy, and multi-replica state semantics are outside M0.
- This release does not claim compatibility with proprietary platforms,
  prompts, protocols, source code, datasets, or private identifiers.
- Creating a tag, GitHub Release, or production deployment is explicitly outside
  this release-gate PR.
