# ADR-0002：所有跨模块契约显式版本化

- 状态：Accepted
- 日期：2026-09-03

## 背景

Compiler、Optimizer、Runtime、Resolver 和 UI 会独立演进。未版本化的自由 dict 会把兼容问题推迟到运行时。

## 决策

跨模块对象使用语言无关 JSON Schema，并在对象中携带 `contract_version`。Pydantic 等语言模型必须实现同一语义。破坏性变更发布新主契约路径（如 `sqg/v1`），旧版本在明确弃用窗口内保持可读或提供迁移器。

v0 是实验性契约，但修改仍需测试、示例和 ADR/变更说明。未知字段默认拒绝，未知枚举默认失败，不做静默回退。

## 结果

可以做兼容性测试、重放历史 Run 和渐进部署；成本是早期变更需要更严格的迁移纪律。
