# ADR-0001：Clean-room 实现政策

- 状态：Accepted
- 日期：2026-09-03

## 背景

项目希望独立实现企业语义自然语言分析的一般能力，同时避免专有实现、商业秘密、私有数据和受限材料进入仓库。

## 决策

只使用公开文档、许可兼容的开源项目、通用标准和独立设计。禁止复制或改写专有源码、Prompt、内部标识、凭据、URL、截图、流量、私有数据或受限文档。所有示例必须为合成数据。每个贡献必须完成 clean-room 来源声明和检查清单。

如果贡献者曾接触相关专有实现，只能描述公开可观察的需求与约束；实现细节必须由未引用受限材料的独立设计推导。存在疑问时停止合并并请求法律/安全评审。

## 结果

优势是来源可审计、社区可参与、架构不被单一产品实现绑架。代价是不能追求内部协议兼容，部分行为需要从公开需求重新定义。
