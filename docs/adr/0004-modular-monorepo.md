# ADR-0004：模块化 Monorepo 与所有权边界

- 状态：Accepted
- 日期：2026-09-03

## 背景

早期团队小，立即拆成多个仓库和微服务会放大版本、CI 和本地开发成本；完全无边界的单体又会让 Compiler、Runtime 和连接器相互渗透。

## 决策

采用模块化 Monorepo。`contracts/` 是语言无关边界；`packages/` 保存可复用纯领域库；未来 `services/` 与 `apps/` 保存部署单元。通过依赖规则、CODEOWNERS（后续）和契约测试保持边界，而不是通过网络调用制造边界。

部署形态由扩缩、故障、权限和发布独立性驱动。模块可以在单进程起步，达到明确条件后再拆服务。

## 结果

原子变更和本地开发简单，仍保留未来拆分路径；需要持续执行依赖规则，避免形成“大泥球”。
