# ADR-0003：禁止直接执行 LLM 生成的 SQL

- 状态：Accepted
- 日期：2026-09-03

## 背景

LLM 可能编造字段、绕过语义口径、生成高成本或危险语句。只做 SQL 文本正则检查不能提供足够保证。

## 决策

LLM 只能生成版本化 SQG 候选。候选必须通过 JSON Schema、确定性图/类型校验、Ontology 绑定、权限与预算策略，再由 Capability-aware Optimizer 生成 Physical Plan。Resolver 只接受受控 Plan Fragment，并以参数化/经过白名单的方式生成目标操作。

不提供“高级模式”“调试模式”或失败回退来执行 LLM 原始 SQL。人工 SQL 工具若未来存在，必须是完全独立的产品和权限边界，不复用问答执行路径。

## 结果

安全、可解释性和跨引擎演进能力提高；代价是操作符和语义覆盖需要逐步建设，早期不能回答所有问题。
